# SpendWise Dashboard

## Project Description

SpendWise is an interactive personal budgeting
application that helps users manage monthly
budgets and track expenses.

Users can set a monthly budget, add expenses,
view spending categories and calculate their
remaining balance.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- DOM Manipulation

## JavaScript Concepts Implemented

### 1. Conditional Statements

Conditional statements validate user input
and determine whether the user has exceeded
their monthly budget.

### 2. Arrays

An expenses array stores multiple expense
records as objects.

### 3. Loops

For...of loops process expense records,
calculate totals and display transactions.

### 4. DOM Manipulation

JavaScript updates dashboard values,
category cards and the expense table
directly in the browser.

### 5. Event Listeners

Submit event listeners allow users to
set budgets and add expenses through forms.

### 6. Functions

Reusable functions organize the application:

- formatCurrency()
- calculateTotalExpenses()
- calculateRemainingBalance()
- displayExpenses()
- updateCategories()
- updateDashboard()

### 7. Calculations

The application calculates total expenses
and remaining balance using arithmetic operations.

Remaining Balance = Monthly Budget - Total Expenses

## Challenges and Solutions

One challenge was connecting JavaScript
to HTML elements correctly.

This was resolved by using document.getElementById()
to select the required elements.

Another challenge was updating the dashboard
when users added expenses.

This was resolved using event listeners,
arrays and DOM manipulation.
